# صور الشخصيات

ضع صورة لكل شخصية هنا باسم **معرّفها** بالضبط (مثل `wave_caller.png`) ثم شغّل:

```
node tools/scan-images.js
```

الشخصية التي ليس لها صورة تبقى على الرسم المدمج. الصيغ: png / webp / jpg / svg.

## المقاسات الموصى بها
- مربعة أو عمودية 4:5، **512×512 على الأقل** (الأفضل 1024).
- الوجه في النصف العلوي وفي المنتصف؛ تُقصّ الصورة لتملأ نافذة البطاقة (بيضاوية)، فاترك هامشًا حول الوجه.
- خلفية شفافة أو بلون العالم تعمل الاثنتان.
