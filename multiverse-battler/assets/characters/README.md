# صور الشخصيات

ضع صورة لكل شخصية هنا باسم **معرّفها** بالضبط (مثل `wave_caller.png`) ثم شغّل:

```
node tools/scan-images.js
```

الشخصية التي ليس لها صورة تبقى على الرسم المدمج. الصيغ: png / webp / jpg / svg.

## المقاسات الموصى بها
- مربعة أو عمودية 4:5، **512×512 على الأقل** (الأفضل 1024).
- الوجه في النصف العلوي وفي المنتصف؛ تُقصّ الصورة لتملأ نافذة البطاقة (بيضاوية)، فاترك هامشًا حول الوجه.
- خلفية شفافة أو بلون العالم تعمل الاثنتان.

## التوليد التلقائي (اختياري)
بدل نسخ الأوامر يدويًا، يمكن للسكربت أن يطلب الصور من خدمة رسم تدعم واجهة `/images/generations` (النمط الشائع).

**١. اضبط الإعدادات** (المفتاح سرّي، لا تضعه في أي ملف ولا ترفعه):

PowerShell (ويندوز):
```
$env:IMAGE_API_KEY="مفتاحك"
# اختياري: $env:IMAGE_API_BASE="https://عنوان-الخدمة/v1" ; $env:IMAGE_MODEL="اسم-النموذج"
```
ماك/لينكس:
```
export IMAGE_API_KEY="مفتاحك"
```

**٢. جرّب بلا تكلفة** (يطبع الأمر فقط):
```
node tools/generate-images.js wave_caller --dry
```

**٣. ولّد شخصية واحدة أولًا** (4 نسخ):
```
node tools/generate-images.js wave_caller
```
ثم افتح `assets/characters/candidates/index.html` في المتصفح لتشاهد النسخ.

**٤. اختر الأفضل** (يقصّها ويسجّلها في اللعبة):
```
node tools/pick-image.js wave_caller 2
```

**٥. كرّر لباقي الشخصيات** أو ولّدها كلها: `node tools/generate-images.js --all` (20 × 4 = 80 صورة، وقد تكلّف مالًا في الخدمات المدفوعة؛ استخدم `--variants 2` لتقليلها).

ملاحظات: يحتاج Node.js 18 أو أحدث، واختيار الصورة يحتاج Python مع Pillow (`pip install pillow`). إذا كانت خدمتك لا تدعم هذه الواجهة فاستعمل الطريقة اليدوية أعلاه.
