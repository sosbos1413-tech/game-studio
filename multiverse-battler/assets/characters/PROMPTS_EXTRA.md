# طقم أوامر لـ ٦٤ شخصية جديدة (١٦ لكل عالم)

شخصيات **أصلية** تسدّ نواقص الأدوار في كل عالم (الجمر بلا دعم، المدّ بلا قاتل أو قناص، نيون بلا ساحر، الغابة بلا دعم). كل عالم فيه: ٣ حرّاس، ٣ مقاتلين، ٢ قتلة، ٣ سحرة، ٢ قناصين، ٣ دعم. والفئات (1/2/3) موزعة.

> **هذي الشخصيات ما دخلت اللعبة بعد.** هذا ملف أوامر للصور فقط. إدخالها في اللعبة يحتاج بيانات (صحة، هجوم، مهارة) وضبط توازن.

## طريقة الاستخدام
1. نفس الأداة ونفس النموذج اللي ولّدت فيهم صورك السابقة، وضع إحدى صورك كمرجع للأسلوب إن أمكن.
2. لكل شخصية: الصق **الأسلوب الثابت** ثم **سطر الشخصية** ثم **الخلفية**. ولّد ٤ نسخ واختر الأفضل.
3. المقاس مربع 1:1 (1024×1024)، وجه واحد، بدون نص.
4. سمِّ الملف باسم **المعرّف** (مثل `ember_blade_dancer.jpg`) وضعه في `assets/characters/`، ثم شغّل `node tools/scan-images.js`. أو أرسل الصور لي.
5. اشتغل **عالم عالم** (١٦ صورة لكل دفعة) عشان يبقى الأسلوب متجانس.

> لا تضف أسماء أنميات أو شخصيات أو رسّامين، حتى تبقى الشخصيات أصلية. وإذا طلعت لك نتيجة تشبه شخصية معروفة، ولّد من جديد.
> لو تستخدم API مدفوع: ٦٤ × ٤ = ٢٥٦ صورة. قلل النسخ إلى ٢ للتوفير.

## الأسلوب الثابت (بداية كل أمر)
```
clean modern anime illustration, high-quality cel shading with soft gradients, sharp fine linework, glossy hair highlights, detailed expressive eyes with layered highlights, muted cinematic colours, bust portrait (head and shoulders), face centred in the upper half, square 1:1 composition, single character, no text, no watermark, no signature, no border
```

## الأمر السلبي (إن كانت الأداة تدعمه)
```
text, letters, watermark, signature, logo, frame, border, collage, character sheet, multiple characters, extra fingers, deformed face, cropped head, blurry, low quality
```
